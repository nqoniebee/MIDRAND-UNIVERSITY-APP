A FEW USEFUL ANSWERS

Before you ask.

Can I use this website offline?

Yes. Extract the complete folder and open website/index.html in a modern browser. All images, media, scripts and the p5.js library are included. A small local server is recommended for consistent saved plans and video captions.

Does saving a module enrol me?

No. The study plan is a personal shortlist saved on your browser. It does not create a university record or reserve a place.

Is this the official MIDRAND UNIVERSITY website?

This is a DSI236 academic prototype. Programmes, staff, events and the campus image illustrate the department website concept and are not official university information.

What do I need for the interactive lab?

A modern browser with JavaScript enabled. The lab uses the bundled p5.js library and a small generated dataset. You can use keyboard-accessible controls and read the same results in a table.

Where is my personal information stored?

The enquiry form keeps your text only in the current page memory. It sends no network request and does not save the form to localStorage. Only module codes in your study plan are stored on this browser. Clear them using the study plan button.
